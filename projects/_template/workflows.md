# Workflows

## WF-001 — Workflow name

- **Goal:** Observable outcome.
- **Trigger:** Event that starts the workflow.
- **Actors:** People and systems involved.
- **Preconditions:** Required state.
- **Success outcome:** End state and evidence.

### Main flow

1. Actor performs an action.
2. System validates and changes state.
3. Observable outcome occurs.

### Alternate and failure flows

- Condition, response, recovery, and owner.

### Rules and telemetry

- Governing business-rule IDs.
- Relevant events, metrics, audit evidence, and privacy constraints.
