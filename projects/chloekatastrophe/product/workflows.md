# Workflows

## Canon change

Identify affected knowledge, verify against accepted facts and decisions, make the smallest additive change, record the decision/change, preserve contradictions, review public continuity impact, and promote generated material only with explicit approval.

## Artifact to publication

Ingest media and honest metadata → assign canonical status and visibility → load approved canon → generate platform-native drafts → human review/edit/approval → publish or copy manually → record publication and metrics → use evidence to revise future work.

## Audience discovery

Test recurring formats such as “Is This a Real Memory?”, “Questions I Was Not Built to Answer,” and “Archivist's Note.” Each item must work without prior lore, contain one clear invitation, and be measured before automation or platform expansion receives priority.

## Visual production

Load Chloe Model v1 → choose a registered performance state where possible → generate → review identity, anatomy, tone, and medium-appropriate variation → retain as generated work until approved.
