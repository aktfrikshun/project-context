# ADR-002: Use Chloe Model v1 for Current Visual Production

**Status:** Accepted

**Date:** 2026-06-27 (alignment decision; model approved 2026-06-26)

## Context

The older archive described a shorter, porcelain-skinned, emerald-eyed Chloe with straight jet-black hair. Image Studio produced and approved a new production identity foundation.

## Decision

Use Chloe Model v1 for new image, video, album-art, and social production unless Allen explicitly requests the older reference-board style. Preserve older descriptions as archive history.

## Rationale and consequences

New work uses the versioned model card, locked traits, turnaround, and performance registry. Historical imagery and documents remain traceable rather than being rewritten.

## Alternatives considered

Continuing the older visual baseline was superseded for production but remains available by explicit request.
