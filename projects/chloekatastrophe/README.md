# Chloe Katastrophe Knowledge Project

Chloe Katastrophe is the formal public identity of Chloe Volkova / Chloe Volkov: a fictional virtual artist, musician, model, explorer, storyteller, and self-reconstructing continuity. Her archive deliberately blurs recovered record, memory, fiction, and generated artifact while maintaining strict internal labels for what is known.

This project is the vendor-neutral, durable knowledge layer for humans, IDE agents, online agents, and future retrieval systems. It contains normalized knowledge and provenance, not application code, media binaries, credentials, or an indiscriminate copy of the source archives.

## Authority and maintenance

Accepted decisions and explicitly canonical records in the FrikShun marketing archive govern narrative and public identity. Chloe Model v1 in FrikShun Image Studio governs new visual production. Project documents describe local implementation and do not automatically become universal canon.

Humans should change canon through reviewed Git changes, preserve the source and reason for each change, and update conflicts or deprecations explicitly. Agents must prefer documented canon to assumptions, distinguish canon from proposals and implementations, and never silently resolve contradictions. A newer lower-ranked source must be preserved and flagged rather than ignored.
