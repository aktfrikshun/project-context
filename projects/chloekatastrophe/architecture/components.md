# Components

## Durable responsibilities

- **Artifact registry:** media metadata, source notes, type, visibility, recovery context, status, tags, and release association.
- **Canon registry:** normalized approved, draft, unresolved, and reference entries with provenance and generation eligibility.
- **Release catalog:** official release metadata and outgoing streaming links.
- **Transformation engine:** platform-specific drafts grounded in selected canon and recent editorial context.
- **Approval/publication ledger:** edits, approvals, attempts, external identifiers, URLs, and failures.
- **Public archive/search:** approved content discovery and permanent pages.
- **Conversation layer:** fan-safe, canon-grounded Chloe interaction with clear disclosure.
- **Metrics and interaction queue:** performance measures and review-first public-comment responses.

The original plan names Artifact, Release, PlatformAccount, PostDraft, PostPublication, Campaign, CanonEntry, conversation, Fan, and FanEvent models. Treat names and fields as current design guidance rather than universal ontology.
