# Security and privacy

## Baseline controls

- Minimize collected data and privileges.
- Authenticate identities and authorize every protected action server-side.
- Encrypt sensitive data in transit and at rest according to applicable policy.
- Keep secrets in managed secret systems, never in this repository.
- Validate untrusted input and encode output for its destination.
- Log security-relevant events without logging credentials, tokens, or unnecessary personal data.
- Patch dependencies through a documented vulnerability process.
- Define retention, deletion, backup, recovery, and incident ownership.
- Threat-model new trust boundaries and high-impact integrations.

Security requirements should identify the protected asset, threat, control, owner, evidence, and exception process. Legal or compliance claims require qualified review; AI output is not approval.
