# Technology guidance

Document technology categories, lifecycle status, selection criteria, supported versions, ownership, and known constraints here. Do not create an unreviewed list of fashionable tools.

For each technology, record:

- capability and intended use;
- lifecycle: proposed, approved, tolerated, deprecated, or prohibited;
- compatibility and operational constraints;
- security and licensing considerations;
- owner and review date;
- related ADRs and projects.

Use [the general document template](../../templates/document-template.md) for a new technology note.
