# Project template

1. Copy `projects/_template/` to `projects/<project-id>/`.
2. Replace placeholders in every file; use `Not applicable` with a reason rather than deleting sections.
3. Add the project to `projects/README.md`.
4. Link applicable shared guidance and accepted ADRs from `overview.md`.
5. Ask accountable owners to review architecture and business rules.

A complete project context contains `overview.md`, `architecture.md`, `business-rules.md`, `workflows.md`, `integrations.md`, `conventions.md`, and `glossary.md`.
